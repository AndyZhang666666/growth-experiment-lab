## 七点界面取舍

app-screen，accent-ladder，seed 1887463023，保留原有红色强调和字体。不迁移框架、不重做官网。

1. 任务是规划、理解停止规则和记录判断，不再以 p 值批准全量。
2. 输入与输出桌面并列；手机单列；平板和手机页签两列，避免三加一的尾行。
3. 曲线和柱图显示真实计算值；关闭结果图的 JS 动画，减少动画模式不出现空白过渡帧。
4. 统计结论与人工上线核对分别展示；保留必要说明，不把边界藏进源码。
5. 取消、错误、过期结果、恢复与导出都有可见反馈；策略表提供键盘按钮。
6. 最小正区间不再四舍五入成零后又称“下界为正”；数字使用等宽布局，提升正文对比度。
7. 检查器首轮 0 FAIL / 1 WARN；输入与输出天然长短不同，保留自然高度，不用空白撑高短面板。已查看三种宽度首屏和全页，以及解读器桌面/手机长页截图，发现图表过渡帧后关闭 JS 动画并复验。
