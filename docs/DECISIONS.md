# DECISIONS.md — 关键决策记录

## 1. 置信区间方法：Newcombe 而非 Wald

**决策**：两比例之差的置信区间用 Newcombe (1998) 方法 10，而非教科书常见的 Wald（正态近似）。

**理由**：
- Wald 在小样本或极端转化率（接近 0 或 1）下会给出荒谬的区间（下界 < -1、上界 > 1，或者 x=0 时区间宽度为 0）
- Newcombe 方法基于 Wilson 区间，在边界情况下仍稳健；大样本时两者几乎一样
- 增长 PM 经常遇到转化率 5% 以下或样本不到 1000 的场景，Wald 不可靠

**备选**：Agresti-Caffo 加 2/4 法也稳健，但文献支持不如 Newcombe 清晰。

**验收**：`scripts/test-stats.mjs` 对照 Newcombe 1998 论文 Table II 的三个例子，误差 < 0.05%。

## 2. 样本量公式：与 Evan Miller 不同

**决策**：用教科书的 n = (z_{α/2} + z_{β})² · [p₁(1-p₁) + p₂(1-p₂)] / δ²，而非 Evan Miller 计算器的公式。

**理由**：
- Evan Miller 用的是 (z_{α/2}·√(2p(1-p)) + z_β·√(...))² / δ²，对零假设下方差的估计方式不同
- 他的公式在 20% 基线、+5% 绝对提升时给 1030，本项目公式给 1091，差 6%
- **两个都对**，只是对 H₀ 方差的假设不同。本项目用教科书公式因为更容易对照手算和其他文献
- `scripts/test-stats.mjs` 同时对照了两个公式，确保都能复现

**已知局限**：本项目没有实现 Evan Miller 的「不等分组优化」（当 treatment 流量受限时如何分配）。当前默认 ratio=0.5 均分。

## 3. 结果解读的三档规则

**决策**：`interpret()` 给出三档结论（可全量 / 继续跑 / 不推），而不是只给 p 值。

**规则**（见 `lib/stats.js`）：
1. **显著且 diff > 0** → 可全量，但要看业务换算（区间下界算最保守收益）
2. **显著但 diff < 0** → 显著变差，别推
3. **不显著**：
   - 如果按观测到的 diff 算，达到 80% power 需要的样本量 ≤ 3 倍现在 → 继续跑
   - 否则 → 差异不显著，别硬推（要检出这么小的差异成本太高）

**理由**：
- 一个没接触过统计的 PM 看到「p = 0.03」不知道下一步该干什么；看到「可以全量，但先看区间下界算最保守收益」就知道了
- 「继续跑还是关掉」的判断标准是业务成本：如果要 10 倍样本量才能检出，不值得等

**备选**：贝叶斯方法能给出「treatment 优于 control 的后验概率」，更直观，但引入先验分布会让 PM 问「这个先验哪来的」，增加解释负担。频率学派虽然拧巴，但规则明确。

## 4. 偷看惩罚模拟器用固定种子

**决策**：`scripts/peeking-sim.mjs` 用固定种子 20260913，保证每次跑出的假阳性率完全一致。

**理由**：
- README 里要引用「偷看让假阳性率飙到 22.5%」这个数字，如果每次跑都变，写 README 时不知道该写多少
- 固定种子 = 可复现 = 可审计。面试官能自己跑一次验证「你这个 22.5% 是真跑出来的还是编的」

**已知局限**：种子固定意味着「运气成分」也固定了。如果想看「跨不同种子的置信区间」，得改成多种子 + 汇总，但那是统计研究的需求，不是产品 PM 的需求。

## 5. 序贯检验用近似边界

**决策**：O'Brien-Fleming 边界用 c·√(K/k) 近似，c = 2.0；Bonferroni 用 z_{1-α/(2K)}。

**理由**：
- 真正的 OBF 常数要解多元正态积分（没有解析解），工程上常用 c=2 或 c=1.96 近似
- Bonferroni 最保守、最好解释（「14 次检查，每次用 α/14」），适合向非统计背景的人说明
- 本项目的目标是「证明偷看有惩罚、alpha spending 能压回来」，不是发论文，近似够用

**已知局限**：真正的 OBF 假阳性率应该精确控制在 5%，这里用 c=2 跑出 6.6%，略高。如果要精确到 5.0%，c 应该取 ~1.977（要数值求解）。

---

## 6. 不做贝叶斯 vs 频率学派的教程

**决策**：全程频率学派（p 值、置信区间），不引入贝叶斯（后验概率、credible interval）。

**理由**：
- 贝叶斯在「treatment 比 control 好的概率是多少」这个问题上更直观，但要解释先验、后验、共轭分布，学习曲线陡
- 大厂的 A/B 平台（Google、Meta、字节）主流仍是频率学派 + 序贯检验，PM 学这套更实用
- 如果要加贝叶斯，应该是另一个项目（`bayesian-experiment-lab`），不要在这个项目里混两套范式

**备选**：至少可以加一页「贝叶斯 vs 频率学派的区别」作为教育内容，不涉及计算。
