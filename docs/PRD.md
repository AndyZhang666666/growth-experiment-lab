# PRD — Growth Experiment Lab

## 用户

做 A/B 实验但没有专职数据科学家支持的增长 PM / 运营。

## 问题

市面上的显著性计算器只回答「这个提升显著吗」，但增长 PM 每天要做的三个判断都回答不了：

1. **实验前**：要跑多少样本才够？公式能算，但不直观 —— 想检出更小的提升，样本量涨得多快？只肯跑 7 天的话，能检出的最小提升是多少？
2. **实验中**：跑到一半看到数字好看，能提前停吗？不能 —— 但没工具证明「偷看提前停」到底让假阳性率飙到多少，PM 只能硬忍着。
3. **实验后**：统计证据、业务效应与护栏分别如何？区间描述什么不确定性，哪些外部上线条件仍未核对？

**我在美团做促销效率优化时的真实痛点**：对优惠券梯度做 A/B 验证，最难的不是跑实验，是这三件事。这个工具把三件事放在一起，并且用模拟证明「偷看提前停」的真实代价。

## 范围

四个页面：

1. **实验设计器**：输入基线转化率、MDE、α、power、日流量 → 输出样本量、预计天数、MDE 曲线、反推「只肯跑 7 天能检出多少」
2. **偷看模拟器**：在声明的合成参数下比较固定样本、重复检查与校正策略，结果可复现、可取消，不承诺通用误报率。
3. **结果解读器**：输入两组转化计数，分开展示统计证据、条件收入情景与人工上线核对，导出带输入和局限的记录。不显著不等于无效，不临时按观测效应延长实验。
4. **实验记录**：8-10 个合成实验台账，展示「一个增长 PM 的实验日志长什么样」

## 不做什么

- 不接真实数据源（无数据库、无用户系统）
- 不做多臂老虎机（聚焦固定分组 A/B）
- 不做贝叶斯与频率学派之争的教程
- 不做实时流式计算

## 成功标准

- 三个页面都能在浏览器完成计算，无需后端
- 偷看惩罚模拟器的数字能写进 README（这是全仓最有价值的证明）
- 结果解读器给出的三档结论，一个没接触过统计的 PM 也能看懂下一步该干什么
