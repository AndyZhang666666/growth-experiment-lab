# Growth Experiment Lab

[在线体验](https://andyzhang666666.github.io/growth-experiment-lab/) · [产品决策](docs/DECISIONS.md) · [验收记录](docs/VALIDATION.md)

把实验设计、停止规则和上线判断分开。显著是证据，不是自动全量的指令。无需登录、无需 API Key，输入与模拟在浏览器本地完成。

## 四个工作区

| 工作区     | 任务与产出                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------- |
| 实验设计器 | 输入基线、MDE、α、power、流量与时间预算，规划两组样本量与时长，导出设计计划                  |
| 偷看模拟器 | 固定零效应与种子，比较四种检查策略；Worker 内运行，可取消，输出参数明确的模拟记录            |
| 结果解读器 | 输入转化计数，查看检验、区间与收入条件情景；人工核对有效性、护栏和最低业务门槛，导出决策记录 |
| 实验记录   | 10 个单次抽样的合成案例；展示预置计划、指标方向、统计量和未解决的核对事项                    |

设计器与解读器只在本机保存输入。损坏或禁用存储仍可使用。上线人工确认不保存；修改实验计数或刷新后需重新核对。默认输入、台账和随机模拟均为合成，不是已发生的业务成果。

## 关键产品判断

- 不显著不能证明没有效果，也不按观察到的差值临时补样本、延长固定样本实验。先核对原计划，到达终点后记录结论；需要再次验证时另立实验。
- 正向证据不自动批准全量。实验有效性、留存/退款/投诉/成本护栏和预先约定的最低业务效应都需另核对。界面手动选项不冒充系统验证。
- 区间乘以假设流量与单次价值，是条件收入情景，不是保底收入、净利润或未来范围的保证。
- 台账每例只抽样一次，不为想要的结论重抽；“按计划继续”来自预置计划尚未完成，不来自当前 p 值好不好看。取消率声明越低越好，不把负差值一律当坏结果。
- 模拟结果始终携带实际参数和种子。修改输入后，旧结果继续显示但标为上一组，图表使用旧结果自身的 α/天数/分母，禁止导出失效记录。

## 计算口径与限制

两比例合并方差 z 检验；差值区间用 Newcombe 方法 10（两个 Wilson 区间组合），Wald 仅作对照。Wilson 公式可对照 [NIST 统计手册](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。这些近似不是小样本精确检验，也不覆盖非随机分流、重复用户、窥看与多重比较问题。解读器仅对“越高越好的转化率”给统计方向，退款等负向指标作为外部护栏处理。

样本量使用本项目既有的正态近似形式，α 为双侧，允许不等分组；时间只是按流量折算的计划值，还需覆盖业务周期、延迟指标和用户独立性。预算过少时不生成虚假可检出门槛。

偷看示例比较结束时一次检验、反复使用原 α、固定 c=2 的 OBF 型近似及 Bonferroni。**OBF 型常数没有按输入 α 校准，不是可直接投入生产的序贯设计**；不再给出未经求解的校准常数，也不声称四种策略误报率应恰好等于 α。

## 已执行的固定模拟与回归

以下只属于记录的合成设定，不能泛化为所有实验的固定误报率。2,000 次实验，14 天，每组每日 500 人，两组真实转化率均 10%，α=5%，种子 20260913：

| 策略            | 判显著比例 |              记录停止总次数 | 最后一天之前停止 |
| --------------- | ---------: | --------------------------: | ---------------: |
| 结束时只看一次  |      4.95% | 99 次显著；2,000 次记录结束 |                0 |
| 每天按原 α 查看 |     22.45% |                  449 / 2000 |              442 |
| OBF 型近似，c=2 |      6.60% |                         132 |              106 |
| Bonferroni      |      2.30% |                          46 |               45 |

偷看判显著比例约为输入 α 的 **4.5×**。其中 D1 / D2 / D3 的次数分别为 94 / 68 / 57，占全部 449 条判显著路径的 49%（219/449）。记录停止与“提前停止”分开计算，最后一天判显著不算提前停止。

既有 power 产物使用每组样本量 3211，检出 811 次，记录检出率 81.1%。统计对照 **24/24** 通过；新增工作流与边界测试另见验收记录。以上数字来自 [results/](results/)，不是用户实验或业绩。

## 开发与验收

Next.js 15 / React 19 / Recharts，保留原有红色强调与四个工作区，静态导出到 GitHub Pages。

```bash
npm ci
npm test
npm run check:release
npm run verify:readme
npm run gen:experiments
npm run build
```

浏览器验收需要 Playwright 与 Chrome，先启动静态服务器：

```bash
TEST_URL=http://localhost:8804/growth-experiment-lab/ node scripts/test-browser.mjs
```

可用 PLAYWRIGHT_MODULE 指定模块，EVIDENCE_DIR 指定截图与下载目录。包含计划/结果导出、输入恢复、人工确认失效、Worker 取消/预算限制、旧结果溯源、键盘策略选择，以及四工作区 × 1440/768/390/360px。
